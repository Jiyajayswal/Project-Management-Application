# Project Management Dashboard

A full-stack project management platform designed to help teams organize, track, and monitor projects from a centralized dashboard. The application provides a comprehensive view of project progress, tasks, timelines, budgets, priorities, team members, and project-related data.

The dashboard allows users to create and manage projects, assign and track tasks, organize work by priority, and monitor project timelines through interactive Gantt-style views. It also includes searchable project data, detailed project views, budget tracking, team and user management, and responsive dashboards for accessing project information across different screen sizes.

The application follows a modern client-server architecture, with a Next.js frontend communicating with a Node.js and Express backend. Project and user data is stored in a PostgreSQL database and managed through Prisma. Redux Toolkit and RTK Query are used for client-side state management and efficient API data fetching, while Material UI Data Grid and interactive charts provide structured ways to explore and visualize project information.

The platform also integrates AWS services to support cloud deployment, database hosting, file storage, API management, serverless functionality, and user authentication. AWS Cognito provides authentication and user management, while services such as EC2, RDS, S3, API Gateway, Lambda, and Amplify support different parts of the application infrastructure.

Overall, the project demonstrates a scalable full-stack application for centralized project planning, collaboration, data management, and progress tracking.
